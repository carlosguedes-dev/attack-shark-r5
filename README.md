# 🦈 Attack Shark R5 Ultra — Experiência Visual

🔗 **[Acessar o Projeto](https://carlosguedes-dev.github.io/attack-shark-r5/)**

## 📌 Sobre o Projeto
Uma landing page interativa e premium desenvolvida para o mouse **Attack Shark R5 Ultra**. Este projeto foca em uma **experiência visual imersiva**, utilizando animações atreladas ao scroll da página, tipografia moderna e design de alta fidelidade para apresentar o produto.

Este é um projeto pessoal criado com fins educacionais para explorar técnicas avançadas de front-end.

## 🚀 Tecnologias Utilizadas
- **HTML5** Semântico
- **CSS3** (Variáveis, Flexbox, Grid, Animações e Efeitos Glassmorphism)
- **JavaScript Vanilla** (Interações, Animações no Scroll, Canvas)

## ✨ Principais Funcionalidades
- **Hero com Vídeo Interativo**: Animação central dinâmica atrelada à rolagem da página.
- **Design Responsivo**: Adaptado para diferentes tamanhos de tela (desktop, tablet e mobile).
- **Scroll Animations (Reveal)**: Elementos da página surgem suavemente de acordo com a posição da leitura.
- **Visual Premium**: Foco total em UI/UX, utilizando cores e gradientes para ressaltar as especificações de performance do produto (39g, 42K DPI, 8KHz).
